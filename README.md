# Greeting App 🌸

This is a **simple and interactive Greeting App** created using **HTML, CSS, and JavaScript**.  
The app greets the user based on the **current time of the day** with smooth animations and a modern UI.

---

## 📌 Features
- Animated gradient background
- Glassmorphism-style UI
- Takes user name as input
- Displays:
  - Good Morning
  - Good Afternoon
  - Good Evening
- Smooth fade-in animation for greeting message
- Input validation for empty name

---

## 🛠️ Technologies Used
- **HTML** – Structure of the app  
- **CSS** – Styling, animations, and layout  
- **JavaScript** – Logic for time-based greeting  

---

## 🎯 Purpose of This Project
- To practice HTML, CSS, and JavaScript together
- To learn DOM manipulation using JavaScript
- To understand time-based conditions
- To create interactive and animated web pages

---

## 🚀 How It Works
1. User enters their name
2. Clicks the submit button
3. App checks the current system time
4. Displays an appropriate greeting with animation
